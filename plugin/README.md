# dsh-auto-send

给 DeepSeek Harness（DSH）桌面版加一个「定时发送」：在输入框写好一条消息，设一个时间，到点由 DSH 自己把这条消息发进当前会话并开始干活。

主要用途是**错峰** —— 把耗 token 的长任务排到便宜的计费时段（卡片里的 `12:00` / `18:00` 两个快按钮就是为这个准备的），你锁屏、切会话、把窗口丢到后台都不影响投递，只要桌面应用还开着。

## 安装

```sh
dsh plugin add dsh-auto-send
```

装完刷新页面（`Ctrl+R`）：输入框右下角、发送按钮左边会出现一个时钟图标。

## 怎么用

1. 在输入框写下要发送的内容（原样投递，不会被改写）。
2. 点时钟图标展开小卡片，按 `12:00` / `18:00` 直接排入，或点「自己定时」选今天/明天/后天 + 时刻。
3. 设好后按钮变成胶囊 `⏰ 18:30 · 剩 2 小时 14 分`，点它改期，点 ✕ 取消。
4. 设好之后继续改输入框，停手约 0.7 秒会自动同步待发内容 —— 到点发的是最后那段。

到点时 DSH 把这条消息作为一条用户消息投递进本会话，并起一个真实轮次，和你亲手按下发送没有区别。

## 边界

- 只对当前会话生效，一个会话挂一条任务；重复任务请用「自动化任务」页。
- 投递走 DSH 自带的 `dsh-schedule`，插件自己不设定时器、不做持久化。
- 桌面应用完全退出时不投递；重启后补投最近一次错过的任务。
- 不解析自然语言（「5 分钟后提醒我」不会自动识别），时间在卡片上填。
