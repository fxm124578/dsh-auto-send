# 定时发送

给输入框加一个「到点自动发」的出口。写好一条消息，设个时间，剩下的交给 Host 调度：你锁屏、切会话、把窗口丢在后台都不影响，只要桌面应用还开着。

## 怎么用

1. 在输入框写下要发送的内容（这段文字会被原样投递，不会被改写）。
2. 点输入框右下角、发送按钮左边的时钟图标。
3. 输入框正上方会展开一张卡片。卡片右下角是确认区：
   - **两个错峰按钮** `12:00`、`18:00` —— 便宜计费窗口。标签上的「今天 / 明天」是算好的：这一档还没到就是今天，过了就是明天。**按下去就直接排入，不需要再确认**。
   - **「自己定时」是左下角的一行下划线文字**，不是按钮。点它，卡片中间展开表单：今天 / 明天 / 后天三选一 + 手写时刻。打开时默认「十分钟后」；`12:30`、`1230`、`930`、`9` 都认，回车或点右下角的 `定时发送` 送出。写不成时间时输入框描红、主按钮置灰，不会猜。再点一次那行字（此时显示「收起」）可以收回去。
   如果选到的时刻已经过去，会自动顺延到第二天同一时刻，并在卡片上提示。
4. 结果如实显示：快按钮直接落到 `✓ 已定时：今天 12:00`。
5. 设定完成后按钮变成胶囊 `⏰ 18:30 · 剩 2 小时 14 分`，倒计时一直可见；点胶囊可以改期，点 ✕ 取消。

到点时，Host 会把这条消息作为一条用户消息投递到本会话，并起一个真实轮次——和你在输入框里亲手按下发送没有区别。注意 Host 投递的是它保存的那份文本，不是去「点」你的输入框，所以触发后输入框里原来的字还在；想改内容就继续在输入框改，停手约 0.7 秒插件会把待发文本同步成最新的，不用重新设定。

## 颜色

卡片右上角有三个小圆点，点一下立刻换色：**跟随主题**（默认，用 DSH 自己的主色）、**暖橙**、**DeepSeek 蓝**。选择会记住。日间 / 夜间模式不需要单独设——卡片只用主题变量取色，DSH 切到哪套主题它就跟着变。

## 边界

- **一个会话只有一条**。已有任务时再次设定就是改期（保留原任务身份与投递记录），不会被解释成第二条任务。
- **只做一次性**。面板里没有「每天 / 每周」，需要重复任务请到「自动化任务」页创建。
- **不解析自然语言**。「8 分钟后提醒我」不会自动识别，时间由你在卡片上填或按快按钮。
- **改内容不用重新点**。设定后继续改输入框，停手约 0.7 秒同步一次待发文本；清空输入框不会覆盖已存内容，取消或投递后不再同步。到点发的始终是 Host 里保存的那份文本。
- **跨夜关机**。Host 重启后只会补投最近一次错过的任务，更早的不会重放。
- 会话被归档时投递会失败（Host 会返回 `schedule/target-archived`），卡片上如实显示错误，不会静默重试。

## 为什么是这样

它没有自己的定时器，也没有自己的持久化：时间、下一次触发、投递记录全部存在 Host 的调度服务里。这一点和「页面里 setTimeout 到点发」的方案有本质区别——后者关掉页面就没了，而这里关掉页面只是关掉了一个显示器。

## 卸载

在「插件」页移除 `dsh-auto-send`。已排定的任务仍在「自动化任务」页里，可以继续取消或保留；卸载只带走输入框旁边那个按钮和卡片，不带走任何已排定的任务记录。
